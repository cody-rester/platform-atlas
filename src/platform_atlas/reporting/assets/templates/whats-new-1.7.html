Standard Mode

Application Audit

For teams that just need a Platform configuration check — no SSH, no infrastructure access, just OAuth and an optional IAG4 API token.

  • Platform OAuth (read-only)
  • Optional IAG4 API token
  • Runs in any environment
  • No keyring or Vault required
~54 rules covering Platform & Gateway4 application config
Extended Mode

Infrastructure Audit

The full Atlas experience — every collector, every check, the deep architecture review you've been running since 1.6.

  • SSH into IAP, Mongo, Redis, IAG hosts
  • MongoDB and Redis runtime config
  • System & filesystem audits
  • Architecture report
~107 rules across Platform, infra, and operations
Tier Commands

Switch tiers from the CLI

A new tier command group lets you inspect and change your active tier without re-running setup.

platform-atlas tier show displays the current tier and what each tier covers. tier upgrade and tier downgrade swap modes for the active config (or for a specific environment with --env).

Need a one-off? Pass --tier to any command, or set ATLAS_TIER in the environment.

Diffs

Cross-tier diffs, called out

Comparing a Standard capture against an Extended one? The diff renderer flags it: rules that don't exist in the narrower tier appear as SKIP, and a banner tells you which rules are directly comparable.

Sessions remember the tier they were captured under, so historical diffs stay honest even after you upgrade or downgrade.

Distribution

WebUI ships separately

Some teams can't accept any server component in their environment. Atlas v1.7 splits the optional WebUI into its own wheel: platform-atlas-webui.

The core CLI wheel platform-atlas is unchanged — install it alone for the strictest environments, or pair it with the WebUI wheel for a browser experience that imports Atlas as a library.

Both wheels are signed and uploaded to GitHub releases on every tag. Pick what your policy allows.

🧭

Sessions bind a tier 1.7

Every session captures its tier at create time, alongside environment and ruleset. Switch sessions, switch contexts. Pre-1.7 sessions are preserved as Extended for historical fidelity.

🛡️

Standard mode is hard-isolated 1.7

Standard captures can't accidentally touch SSH, Mongo, or Redis — the registry, the credential store, and per-collector guards all enforce the boundary. No surprise connection attempts.
